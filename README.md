🏦 Professional Bank Management System | C++ | OOP

من فترة وأنا شغال على مشروع بحاول من خلاله إني أطبّق مبادئ الـ Object-Oriented Programming بشكل عملي حقيقي، مش بس نظري.

النتيجة: نظام إدارة بنكي كامل مبني بالـ C++، بيغطي:

✅ إدارة العملاء (إضافة، تعديل، حذف، بحث)
✅ إدارة المستخدمين وصلاحياتهم
✅ عمليات الإيداع والسحب
✅ حساب إجمالي الأرصدة
✅ نظام تسجيل دخول أساسي

المشروع اتبنى بالكامل على مبدأ الفصل بين الطبقات (Separation of Concerns): كل شاشة (Screen) منفصلة عن منطق البيانات (Business Logic)، واستخدمت Inheritance بشكل حقيقي بين الكلاسات (زي clsPerson كأب لـ clsBankClient و clsUser)، بدل ما أخلي كل حاجة في كتلة واحدة.

لكن الحقيقة إن الشغل لسه مكملش. النسخة الحالية بتاعت المشروع هي مجرد الأساس. أنا حاليًا بجهز للنسخة الجاية اللي هتضيف طبقة كاملة من الاحترافية:

🔐 تشفير كلمات المرور بدل التخزين الصريح
📝 نظام Logging لتسجيل كل عملية مهمة
🚫 قفل تلقائي للحساب بعد محاولات دخول فاشلة (زي أي نظام بنكي حقيقي)
🛂 نظام صلاحيات متكامل لكل مستخدم
💸 شاشة تحويل أموال بين الحسابات + Log خاص بيها
🧪 اختبارات (Testing) للتأكد إن العمليات الحساسة (الرصيد، الصلاحيات) شغالة صح

بالنسبالي المشروع ده مش مجرد كود، ده رحلة بتحول مشروع تعليمي بسيط لحاجة أقرب لمنطق الأنظمة الحقيقية، خطوة ورا خطوة.
